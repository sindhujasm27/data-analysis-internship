# Data Analysis Internship

## Overview

This repository contains my Data Analysis Internship tasks completed using R. The project covers data cleaning, exploratory analysis, data visualization, statistical analysis, predictive modeling, and comprehensive reporting.

## Dataset

The project uses a publicly available dataset for analysis and modeling.

The data was cleaned, explored, visualized, and analyzed using R and relevant R packages.

## Weekly Tasks

### Week 1 – Data Cleaning and Preliminary Analysis

The first week focuses on:

* Dataset understanding
* Data cleaning
* Data preprocessing
* Handling missing values
* Data type checking
* Summary statistics
* Preliminary exploratory analysis

**Folder:** `Week-1-Data-Cleaning`

### Week 2 – Data Visualization

The second week focuses on visual exploration of the dataset.

Topics include:

* Univariate analysis
* Bivariate analysis
* Distribution analysis
* Comparison of variables
* Correlation visualization
* Data-driven graphical insights

**Folder:** `Week-2-Data-Visualization`

### Week 3 – Data Analysis and Modeling

The third week focuses on statistical analysis and predictive modeling.

Topics include:

* Correlation analysis
* Feature analysis
* Model preparation
* Model training
* Predictions
* Confusion matrix
* Model performance evaluation
* Interpretation of results

**Folder:** `Week-3-Data-Analysis-and-Modeling`

### Week 4 – Comprehensive Data Analysis Report

The final week integrates the work completed during the previous weeks into a comprehensive report.

It includes:

* Dataset overview
* Data cleaning process
* Exploratory data analysis
* Data visualization
* Statistical analysis
* Predictive modeling
* Model evaluation
* Key findings
* Final conclusions

**Folder:** `Week-4-Comprehensive-Report`
